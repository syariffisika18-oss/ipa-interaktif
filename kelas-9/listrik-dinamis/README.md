# Listrik Dinamis — Modul IPA Interaktif Kelas IX

Modul nyata pertama yang menerapkan Template Universal IPA.

Alur: Orientasi → Engage → Explore (Concrete) → Explain (Pictorial) → Elaborate (Abstract) → Evaluate (20 soal) → Reflect.

Bagian CPA diadaptasi dari `CPA_Listrik_Dinamis_Seri_Paralel_v11_20Soal.html`, termasuk simulasi seri/paralel, kontrol 1–3 lampu, tegangan 3–12 V, hambatan 4–20 Ω, sakelar, lepas lampu, indikator terang, animasi aliran, representasi pictorial, penurunan persamaan, evaluasi 20 soal, zoom, dan responsif HP.

Refleksi memakai backend Google Apps Script yang sama dan masuk ke REFLEKSI / RESPON_TERBARU / DASHBOARD Guru.
